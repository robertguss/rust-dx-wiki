mold 3.0.0 is a new major release of the high-speed linker. As we announced in the [2.42.1 release notes](https://github.com/rui314/mold/releases/tag/v2.42.1), we have rewritten mold from C++ to Rust, and this is the first release of the Rust version. 2.42.1 is the last release of the C++ version.
